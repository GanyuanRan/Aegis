# Artifact Bootstrap Fixtures

These sample manifests are bootstrap fixtures for `artifact-schema-check.sh`.

They are not authoritative runtime outputs.
They exist so Phase 5 can validate the minimum field set defined in:

- `docs/current/AEGIS_ARTIFACT_SCHEMA_BASELINE.md`

Long-task continuation fixtures additionally cover:

- `TodoCheckpointDraft`
- `ResumeStateHint`
- `DriftCheckDraft`

Goal-framing and subagent handoff fixtures additionally cover:

- optional `TaskIntentDraft` goal fields
- `SubagentContextPacket`

These are draft / hint fixtures only. They are not durable runtime records and do not grant completion authority.
